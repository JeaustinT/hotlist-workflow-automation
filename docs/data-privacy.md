# Data privacy

Original operational workbooks, source packages, and operational VBA are confidential analysis material and are not distributed in this repository.

The demonstration uses a clean workbook containing only synthetic records. Analyst names, organizations, invoices, locations, identifiers, amounts, dates, comments, mappings, and history are fictional. Transactional relationships are recreated synthetically rather than retained from production. Email addresses use example.com only; corporate email addresses will not be included.

Screenshots are genuine captures from the aligned synthetic demo. Four owner-approved Excel Desktop PNGs have been inspected at full resolution for privacy; no unnecessary PNG metadata was present. The two explanatory SVG diagrams are privacy-reviewed and are not runtime captures. The repository demonstrates the workflow and engineering approach rather than exposing production data.

## Publication controls

1. Keep confidential materials and analysis outside the repository.
2. Create demo assets from clean files; deleting visible data from operational workbooks is insufficient.
3. Review workbook hidden content, metadata, names, relationships, links, connections, cached records, embedded objects, and VBA before tracking any future workbook.
4. Search candidate text and extracted workbook content against confidential names, domains, invoice identifiers, and other IDs without copying that comparison list into the repository.
5. Permit only fictional example.com addresses. Inspect screenshots for accidental personal or organizational information.
6. Review the exact staged diff and tracked file inventory before every commit. Ignore rules reduce accidents but do not guarantee privacy.
7. Keep the repository private throughout development. A later public release requires explicit approval and a fresh privacy review.

No license or distribution rights are implied. The repository contains a clean synthetic demonstration and its source, not a sanitized copy of an operational workbook.
