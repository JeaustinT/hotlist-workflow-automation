1. Download the accepted 0.3.2 workbook; verify SHA-256 `33573d72b238baab6c96716912a113ea0ea36da8c71b8e09f44e40527981424f` before opening.
2. Use a disposable working copy outside the repository. Run the accepted default synthetic fixture: Alex Morgan, Jordan Lee, and Taylor Smith available with weights 100%, 50%, and 100%. Do not invent a new benchmark or claim that every edge scenario is covered.
3. Confirm 48 assigned, 12 exceptions, and summary totals 20 / 8 / 20. The initial seed summary is not this completed-run summary; capture after processing.
4. If showing progress, enter only fictional text such as “Demo follow-up logged” in Agent Comment, then save progress. Never enter real operational comments or personal information.
5. Wait for processing to complete and the lock to release. Control's lock-user cell can temporarily contain the local Excel user name: exclude the technical J:K block, and never capture an active lock.
6. Crop to the relevant worksheet grid and headings. Exclude the Excel profile/avatar, signed-in account, window title/path, corporate sensitivity banners, OneDrive/SharePoint tenant URLs, notifications, Windows taskbar, and other workbook tabs/windows. Check every cell in the frame.
7. Prefer readable desktop crops about 1,200–1,800 pixels wide. Use the demo's neutral styling, clear headings, and visible synthetic labeling. Do not add company branding.
